# AI Fairness Bias Detection Example

This example demonstrates a simple AI system that exhibits an unintentional bias in its decision-making process. It then includes a basic "AI Safety Audit" function to detect and report on potential fairness issues by comparing outcomes across different predefined groups. This illustrates a fundamental aspect of ethical AI safety: ensuring fair and equitable treatment.

## Language

`python`

## How to Run

Save the code as `main.py` and run it from your terminal using `python main.py`.
